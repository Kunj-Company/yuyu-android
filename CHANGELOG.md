# Changelog

All notable changes to Yuyu for Android. The app shows this file on the About
screen (Account → About Yuyu), so write entries for the people using the app.
Versions follow [semantic versioning](https://semver.org); releases are built
by GitHub Actions (see [docs/RELEASING.md](docs/RELEASING.md)).

## [Unreleased]

### Added
- Explore tab: discover and search public events, first in the bottom bar as on iOS.
- About screen with what's new, the people who build Yuyu, and the version.
- Schedule shows the hall each session is in and the event venue, with a map link.

## [0.1.0] - 2026-10-27

The first release.

### Added
- Connect to your community's Yuyu server and sign in with email and password, a two-step code, or Google.
- Tickets: your registrations, a live ticket that updates when you're checked in, and tickets that open offline at the door.
- Event pages with registration forms, the programme and speakers; feedback forms and certificates.
- Event reminders before your events start.
- Organisers: an event hub with live counts, guests to search, approve, decline and add, and emails to guests.
- Check-in: scan tickets, type a code or search by name; fast mode; an offline guest list that syncs later; door stations unlocked with a PIN.
- Schedule for everyone on the organising team, saved for offline use, with speakers, a live countdown for each session, and what's on now and next.
- Day-of controls: running-late delays, opening and closing feedback, and closing sign-ups.

### Fixed
- Opening the camera to check guests in no longer closes the app.
- The app recovers instead of closing when the phone's secure storage or settings files are damaged.
